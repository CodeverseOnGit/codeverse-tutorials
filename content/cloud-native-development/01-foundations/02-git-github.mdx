## Why this chapter exists

Every deployment pipeline you'll build later starts with a `git push`.
Understanding branching, merge conflicts, and PR workflows now saves
you from breaking shared code later.

## Try it yourself

```bash
git checkout -b feature/my-first-branch
git add .
git commit -m "Add feature"
git push origin feature/my-first-branch
```

## What to build by the end

Open a pull request on a public repo (even a typo fix) and get it merged.
