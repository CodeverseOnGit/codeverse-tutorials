## Why this chapter exists

Every cloud native tool you'll touch — Docker, Kubernetes, CI runners — is a thin
wrapper around Linux primitives. Skipping this chapter is the #1 reason people
get stuck debugging containers later.

## Try it yourself

```bash
# Inspect what's listening on your machine
sudo ss -tulpn

# Watch process resource usage live
htop
```

## What to build by the end

A cheat-sheet repo of the 20 shell commands you'll use daily, with real
examples from your own machine.
